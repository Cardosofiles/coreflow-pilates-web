# MISSÃO

> Na página @src/app/(common)/presentation/page.tsx você irá utilizar o componente @src/components/ui/tabs.tsx para criar uma página para cada uma das áreas listadas acima.

- Deve construir as tabs com o propósito de apresentar a aplicação e suas tecnologias.
- Deve ter um carrossel card (componente card) com os desenvolvedores ([api.github](https://api.github.com/users/Cardosofiles)) para cada um dos usuários
- Em cada página 'tabs' deve ter os svg de cada tecnologia (/public/assets) de forma que irá ilustrar o visual
- Deve ter animações como as da página LandingPage (page.tsx)
- Deve colocar referencia para a Instituição, Coordenador do curso, professor da disciplina
